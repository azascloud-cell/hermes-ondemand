# Account Farming Strategies

Strategies for creating and maintaining high-durability accounts while bypassing anti-bot systems.

## Core Principles
- **IP Hygiene:** Never use static IPs or WiFi for mass registration. Use mobile data with Airplane Mode ON/OFF to rotate IPs between each account.
- **Browser Fingerprinting:** Use anti-detect browsers (e.g., AdsPower, Dolphin{anty}) to create a unique browser profile for every single account.
- **Human Behavior:** Mimic natural user behavior (slow typing, random delays) to avoid triggering "Robot" or "Verify it's you" challenges.

## Workflow: The Anti-Robot Blueprint

### 1. Preparation
- Create a new browser profile in the anti-detect browser.
- Rotate IP via Airplane Mode.
- Prepare a recovery email from a stable, separate provider (e.g., ProtonMail) to avoid domino bans.

### 2. Registration
- Register the account using a virtual number (nokos).
- Complete the registration process without logging out.

### 3. Immediate Hardening (The Lock)
- **Recovery Email:** Set the recovery email immediately while still in the initial session.
- **Profile Completion:** Add a profile picture or basic info to make the account look authentic.

### 4. Account Warming (The Trust Build)
Perform these actions to increase the account's trust score and prevent "checkpointing":
- **YouTube Activity:** Search for random videos, watch for a few minutes, Like, and Subscribe to 1-2 large, reputable channels.
- **Content Creation:** Upload a short (5-10s) private video recorded fresh from the device.
- **General Usage:** Use the account for a few days for light, natural activity before using it for automation or sales.

## Pitfalls & Troubleshooting
- **Robot Challenge:** If "Verify it's you" appears, stop immediately. Wait 24-48 hours. Change IP and device fingerprint before retrying.
- **Domino Ban:** Avoid using a single recovery email for too many accounts. Use a **Cluster Strategy**: 1 Recovery Email $\rightarrow$ 5-10 target accounts.
- **Account Death:** Accounts created without warming or recovery emails are high-risk. Priority should be given to "Aged" accounts.
